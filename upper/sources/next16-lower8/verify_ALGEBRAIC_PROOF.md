# 有理数探索から得られた代数実数対の厳密認証

**有理数対ではないが、正の最小な代数実数の対は0〜7階一致・8階差を満たす。** したがって、B_min の対象を元の正の実数パラメータ模型とする場合には、この対も下界8を与える。一方、「全ての率・重み・初期値が有理数」という今回の指定は達成していない。

## 数体と対の正本

κ は

    p(k)=110119472 k³+2679399000 k²+20959796655 k+51676380000

の唯一の実根とする。κ≈−5.04088983861486012443536841701133。p は有理数上既約。`verify_ALGEBRAIC_PAIR.json` は p の整数係数と κ の有理隔離区間を含み、全ての模型定数を Q(κ) の元として記録する。各配列 `[a,b,c]` は a+bκ+cκ² を意味する。従ってこのファイルは数値近似を含まない有限の厳密定義である。

左は S0=β=1、k=κ、N0=12。感染初期値は

    r = 992306862748/6134555965
        +(870278610508/18403667895)κ
        +(303489264832/92018339475)κ²,

回復初期値は R0=11−r。

右は T0=4/5、C=(1,1/4)、K22=−3、N0=12 とする。他の定数の短い定義は次のとおりで、d1,d0,g,v は探索の Cramer 式に h=−1/5,k=κ,r を代入して得る。証明はそれらが探索式を満たす事実に依存せず、完成した全状態模型を直接検査する。

    c=v/g, a=d1−3, b=3a−d0,
    K21=4(c−3), K12=b/[4(c−3)],
    K=[[-a,K12],[K21,−3]], gamma=g.

初期値は z0=5r/4、z1=(5/4)r(1+κ−r)+(25/16)r²、J0=z0/g とし、

    alpha=c−d1,
    beta_lin=[3(d1−c)−d0]/(c−3),
    s=(z1−gr)/z0,
    Z01=J0(beta_lin−s)/(beta_lin−alpha),
    Z02=4J0(s−alpha)/(beta_lin−alpha),
    Rstar0=12−4/5−Z01−Z02.

数体での完全展開は verify_ALGEBRAIC_PAIR.json にある。

## 模型条件の厳密検査

`verify_algebraic.py` はまず SymPy の有理多項式根隔離で p の唯一実根を幅10^−100以下の有理区間に隔離し、その区間内の根数が1であることを確かめる。各数体元は p による次数3未満の剰余に直し、Horner の区間計算で有理上下界を求める。以下の正性は全て下端>0で認証した。表示した小数は説明用であり、判定には使わない。

|量|近似値|
|---|---:|
|r|7.18927598212685842|
|R0|3.81072401787314158|
|g|1.17790658752517414|
|Z01|7.03000510071382658|
|Z02|2.39715327740993681|
|Rstar0|1.77284162187623661|
|K12|2.62843161539455435|
|K21|4.05920045065898237|
|第1列和の負|1.05360874496104530|
|第2列和の負|0.371568384605445649|
|−trace K|8.11280919562002767|
|det K|4.66909678912419096|

C>0, Ce1=1 は定義から成立。Hurwitz は負の trace と正の determinant、Metzler は非対角正性から成立する。可制御行列式は K21≠0、可観測行列式は直接 `det([C;CK])` を計算し非零を確認した。コードで用いる展開は K12−wd−w(−a+wK21)（w=1/4,d=3）。従って二区画実現は最小であり、余分な不可観測区画の付加ではない。

左右の全人口初期和は数体で12に等しい。また

    (S+X+R)'=0,  (T+Z1+Z2+Rstar)'=0

を全状態多項式の恒等式として確かめた。

## 出力の階数

左右の全状態多項式ベクトル場を直接作り、出力 y=SX、ystar=gT(Z1+Z2/4) について Lie 微分を0〜9階まで反復した。係数・代入値には SymPy ANP の有理係数数体演算を使い、全演算の後に p で剰余を取る。

出力微分差 ystar^(j)(0)−y^(j)(0) は j=0,…,7 で数体の零。j=8 は非零で、同じ有理区間評価により

    ystar^(8)(0)−y^(8)(0) > 0,
    近似値 55078505.6206515378

となる。全状態と出力の0〜9階の剰余係数は `verify_ALGEBRAIC_LIE.json` に保存した。N0 に関する微分和も j=1,…,9 の全てで零である。固定された代数数を含む多項式ODEの解析性より、有限の非零微分差は出力 germ が異なることを意味する。

これは有限の正確な反例対の認証であり、探索範囲全体の分類や一般次数への定理ではない。分母や模型条件を満たさない候補を数値上の誤差で通す処理はない。

## 実行と限界

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 timeout 1800 python3 -B studies/R044/next16-lower8/verify_algebraic.py
```

1 process、1 thread、約3.54秒、peak RSS 53212 KiB。各計算は1700秒・4 GiBに制限した。

初回は0〜7階一致・8階非零を確認した後、8階差を仮に負とした符号検査だけが失敗した。実際の正の差に合わせて符号検査を直し、全計算を再実行した。失敗ログは `verify_algebraic_first_failure.log` に保存している。対の定義は修正していない。

生成に使った Cramer 式・r の復元式は同研究チームの別担当から受け取った。従って盲検や外部の独立検証とは呼ばない。完成模型から直接作った全状態 Lie 微分の別実装である。主担当の `taylor_algebraic.py` は Fraction 三成分商体の Taylor 再帰を別に実装し、全状態・出力0〜9階の全列が本 Lie 実装と一致した。正性・最小性・根の検査も別に通過した。結果は `TAYLOR-ALGEBRAIC.json`（PASS）。

h=−1/5 に固定した消去の B 成分は上記の既約三次 p(k)=0 なので、この成分上に有理数 k は存在しない。この局所的な有理性障害は、別の h や他成分の全てを排除しない。κ は既約三次の根なので、この対を有理数対と表記してはならない。しかし正の実現一般が0〜7階一致を禁じる、という障害候補はこの例で否定される。有理数対の有無は別に残る。
