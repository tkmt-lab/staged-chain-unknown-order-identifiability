# 同じ根・同じ時間での厳密接続

この文書の量は箱内の**一つの正確な根**で評価する。区間の端点を互いに独立な模型係数として採用しない。添字 j は Taylor 係数ではなく通常の t 微分値を表す。

## 接触系の定義と根

左模型は β=C=S₀=1、X₀=r、K=k とする。元ODEから

    y_j = Σ(i=0..j) binom(j,i) S_i X_(j−i),
    S_(j+1) = −y_j,  X_(j+1) = k X_j + y_j

を作る。q=S+h と置き、qz=y の積の微分から

    z_j = { y_j − Σ(i=1..j) binom(j,i) q_i z_(j−i) } / (1+h)

を定義する。u=(d₃,d₂,d₁,d₀,g,b₂,b₁,b₀) に関する残差は

    ℛ_j = z_(j+4)+d₃z_(j+3)+d₂z_(j+2)+d₁z_(j+1)+d₀z_j
          −g y_(j+3)−b₂y_(j+2)−b₁y_(j+1)−b₀y_j.

先頭8式 ℛ₀=…=ℛ₇=0 を線形系 A(x)u=b(x) として解く。全箱の消去pivotが0を除き、1+h>0 なので、この定義は箱の近傍の有理解析関数を与える。検証対象 F(x)=(ℛ₈,ℛ₉,ℛ₁₀) はこの定義である。

指定の有理端点箱を1024-bit二進格子へ外向きに拡張した閉凸箱を B とする。自動微分で J(B)⊇DF(B) を計算し、その区間中点行列の**有理逆行列**を C₀ とする。逆行列の積が厳密に単位行列であることも Fraction で検査した。

    T(x)=x−C₀F(x),
    T(B) ⊂ x₀−C₀F(x₀)+(I−C₀J(B))(B−x₀) =: W.

保存された有理端点比較で W⊂int B、かつ ||I−C₀J(B)||∞<1。平均値積分により T は B 上の収縮であり、Banachの固定点定理から一意固定点が存在する。C₀は可逆なので固定点と F=0 は同値。さらに W が入力の正確な `certificate.box` と各 `center±radius` の双方の厳密内部にあることを**有理数比較**した。したがって拡張箱だけでなく指定箱自体にも根が存在し一意である。この同じ根では定義により ℛ₀,…,ℛ₁₀=0 が厳密に成り立つ。

区間演算は整数端点/2¹⁰²⁴で行う。加減は格子上で厳密、積は4端点積の最小を床・最大を天井へ丸め、逆数も端点の逆数を床・天井へ丸める。0を含む分母を拒否する。Gaussian消去を含む全有理演算の包含性と、積・商の微分則による自動微分の包含性を用いる。浮動小数は表示だけで、認証には使わない。

## 同じ根の正実現

    D(s)=s⁴+d₃s³+d₂s²+d₁s+d₀,
    P(s)=s³+(b₂/g)s²+(b₁/g)s+b₀/g.

各入力極区間で D の端点が厳密逆符号、D′が0を除き、区間が負で相互非交差であることを再計算する。IVTと単調性から各区間に一意根があり、Dは4次なのでこれが全根。順に λ₀<…<λ₃ とする。全箱の係数包含でこれを検査するため、接触根での D にも適用できる。

K の対角は λ_i、下副対角は1、残りは0。従って Metzler、Hurwitz であり、列和は最初の3列が λ_i+1、最後が λ₃。全て厳密負と検査する。

H_j を P(s)/D(s) の s^(−j−1) 係数として j=0,…,3 まで計算する。H₀=1、n=(1,b₂/g,b₁/g,b₀/g) として

    H_j=n_j−Σ(i=1..j) d_(4−i) H_(j−i).

Q=[e₁,Ke₁,K²e₁,K³e₁] は単位上三角であり det Q=1。C Q=(H₀,H₁,H₂,H₃) と定める。Qの第1列がe₁なので Ce₁=H₀=1 は厳密。Kの特性多項式は D。伝達関数 C(sI−K)⁻¹e₁ と P/D は分母 D、分子次数≤3で、無限遠展開の先頭4係数が一致するため全体が等しい。有限の近似一致ではなく、この代数的定義の帰結である。

観測行列 O=[C;CK;CK²;CK³] を作り、初期状態 Z を

    O Z = (m₀,m₁,m₂,m₃)ᵀ,
    m_j=z_j/g−Σ(l=0..j−1) H_(j−1−l)y_l

で定める。全消去pivotが0を除くので O は可逆。これは X′=KX+e₁y を反復微分した式であり、右出力の z_R=gCX_R の初期0〜3階を所要値に合わせる。

厳密には、まず左 y を入力とする強制線形状態を用いれば、この式から gCX の0〜3階は z と一致する。q(0)=1+h と q′=−y を合わせ、右の非線形feedbackに戻した場合にも、j階の状態微分が必要とする入力は j−1階以下なので、j=0,1,2,3 の帰納で同じ初期整合が得られる。

計算は C_i>0、Z_i>0、g>0、両側 R(0)>0 を全て認証する。右 β=g、S_R(0)=1+h、左 X_L(0)=r。N=100 とし各側 R(0)=100−S(0)−ΣX(0)。R′=−1ᵀKX とすると

    (S+1ᵀX+R)′=−y+1ᵀ(KX+e₁y)−1ᵀKX=0.

左右とも総人口100である。左は k<0、C=e₁=1 なので最小。右は det Q=1 と det O≠0 により最小。多項式ODEは実解析局所解を持ち、厳密正初期値は十分小さい共通時間区間で正性を保つ。

## 等号と15階の分離

右模型で q_R=S_R、z_R=gCX_R とする。伝達関数恒等式またはCayley–Hamiltonにより、任意の右初期状態について

    D(∂)z_R=gP(∂)y_R,  y_R=q_R z_R,  q_R′=−y_R.

左から作る q=S+h,z=y/q と、右の q_R,z_R は q₀ と z₀,…,z₃ が一致する。これは上の初期moment構成による厳密等号である。

ℛ_j=0 は左 z_(j+4) を右と同じ微分再帰で定める。右辺の最大階は z_(j+3) と y_(j+3)。q′=−qz の式と合わせ、j=0,…,10 について順に帰納すると z の0〜14階、q の0〜15階、y=qz の0〜14階が一致する。したがって区間差が0を含むという情報を使わず、**0〜14階の等号**が証明される。

次階では既に一致した全ての項を引き算すると

    z_L^(15)(0)−z_R^(15)(0)=ℛ₁₁,
    y_L^(15)(0)−y_R^(15)(0)=(1+h)ℛ₁₁.

自作コードはこの残差式とは別に、全状態の元ODEを左右それぞれ15階まで直接再帰し、その差の区間も0を除くことを確かめる。どちらも同じ一意根とその極・実現から計算した包含である。0〜14階の差区間の零包含は整合検査に留める。

## 任意の共通人口

任意の実数 N>0 に対し a=N/100 とし、両側に同じ変換

    (Ŝ,X̂,R̂)=a(S,X,R), β̂=β/a, K̂=K, Ĉ=C, ŷ=ay

を施す。観測式では (β/a)(aS)C(aX)=ay。元ODE、回復式、保存則は全て a 倍され、総人口は N となる。正性は a>0、KとCの条件・可制御性・可観測性は行列不変から保存される。時間 t は変更しない。従って全 j≥0 で差は a 倍、0〜14階は0、15階は非零のまま。

B=14 では異なる解析germを区別できないので各 N>0 で B_min(1,4)≥15。既存の上界15を同じ模型・同じBの定義で受け入れるなら B_min(1,4)=15。人口100での上界だけでも、逆変換 a=100/N により任意人口の対を人口100へ移せるので全Nの上界に移せる。この仕事は上界の大域消去証明を再実行していない。
