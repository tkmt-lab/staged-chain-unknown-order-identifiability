# 一般枝の全係数消去と実候補の排除

入力は next15-upper/PROOF.md の残差 F と11次元空間 E。ここでは h≠0, g≠1 を扱う。
D=d/d(log S) として order(F)≥7 なら
F=λ(W+tDW+uD²W+wD³W), λ=288k²h²。
p(j)=1+tj+uj²+wj³, a=p(1), b=p(2) とおく。

## 最高係数と除算

L²,SL²,S⁴,S³L,S²L の比較から a≠0。
g≠1 と k≠0,h≠0 から p(2),p(3),p(4) は全て非零。
従って

    h=1/(12a), p(3)=54ab,
    E=p(4)=216ab+4a−6b−1,
    k=−3456ab/E, g=1−1728b²/E,
    t=18ab+3a−3b/2−11/6,
    u=−27ab−5a/2+2b+1,
    w=9ab+a/2−b/2−1/6.

除算は abE≠0 の枝内だけで行う。a=0 は SL² の矛盾、b=0 または E=0 は g=1 枝に戻る。
g=1 の枝は別証明書 check/exception.json で扱う。
h>−1 の物理条件から a>0 または a<−1/12。特に a=−1/12 は T0=0 の class 外である。

## 残る線形消去

G=F−λ(W+tDW+uD²W+wD³W) の SL,L 係数を (r,d1) に解く行列式は

    27648 b²/(a E²) ≠0.

解は derived.json の r,d1。
S³ の v 係数は −1、S² の d0 係数は1なので順に一意に消去できる。
途中に新しい零分母枝は生じない。その結果は

    d0=−144b²(12a+1)^5(6b+1)/(a²E²),
    G=8b² P(a,b) S/(a³E²) + b² Q(a,b)/(6a⁴E²).

P,Q は derived.json に全係数を保存した a六次・b二次の整数多項式。
derive.py は物理時間微分から F を生成し、残り9係数が恒等的に零になることも検査する。

## 射影由来の例外を除算前に処理

    Res_b(P,Q)=2916(12a+1)^7 C(a) H(a),
    C(a)=432a³−252a²+24a−1,
    H(a)=8916100448256a^12+42103807672320a^11
        +92714373218304a^10+51391412305920a^9−698600816640a^8
        −832540114944a^7+37764817920a^6+3285494784a^5
        −315786240a^4+11546880a³−222436a²+2180a−9.

a=−1/12 は上記物理条件で除かれる。
C=0 では P,Q の b² 係数が同時に零となるため、通常の二次式 resultant の零だけでは有限 b の解といえない。
C で剰余を取ると

    P mod C=(5/6)[(637632a²−68688a+3168)b+506016a²−54264a+2399],
    Q mod C=−(5/3)[(2229120a²−234360a+10710)b+870336a²−89844a+4039].

この2一次式の b-resultant は

    R=75(10611412992a⁴−2268182016a³+221862528a²−10765564a+238847).

Q[a] で gcd(R,C)=1。CERTIFICATE.json に U R+V C=1 の厳密有理係数 Bezout 証明書を保存した。
従って C=0 の有限 b 共通解はない。先頭係数の同時消失による偽候補を捨てる処理であり、未処理の除算ではない。

## H の候補と正性

H=0 では一次 subresultant から b=−N/(18M) が一意に定まる。

    N=3547348992a⁸+9178914816a⁷+2612984832a⁶−105836544a⁵
      −1598400a⁴+3112416a³−73572a²−4a+3,
    M=895795200a⁸+1618403328a⁷−229174272a⁶+15593472a⁵
      +1978560a⁴−378720a³+24084a²−396a+1.

gcd(M,H)=1。bを逆代入した P,Q の分子は H で割り切れる。
実数体上の候補をすべて調べるため、H の Sturm 列を有理数で計算した。
総実根数は4。次の各区間にちょうど1根あり、これですべてである。
区間の端点は表示した整数を 10^9 で割った値である。

|aの隔離区間×10^9|厳密に負となる量|排除理由|
|---|---|---|
|[−777954024,−777954023]|g|β,γ>0 に反する|
|[−118906418,−118906417]|d1|Hurwitz 実行列の d1=−tr K>0 に反する|
|[−114192897,−114192896]|d1|同上|
|[25568747,25568748]|r|X0=r>0 に反する|

符号は小数近似で判定していない。各量へ b(a) を代入した既約有理式について、分子・分母の Sturm 区間根数をともに0と確認し、左端の有理数で符号積−1を確認した。
分子・分母と根数・符号は CERTIFICATE.json に全て保存した。
classify.py --explore の小数は探索用の表示だけであり、certify.py の判定は有理数と記号演算のみである。

したがって全係数一致の実代数候補4点は残るが、すべて正の模型の必要条件に反する。
Hurwitz Metzler・正の初期値を持つ実現候補はなく、人口・最小性・全状態の構成段階に進む候補は残らない。
g=1,h=0 の別枝と合わせると、出力0〜8階一致から germ 一致が従う。

## 再現と試行

repo root から、各コマンドに timeout 1800 と数値ライブラリ thread=1 を設定し、derive.py、classify.py、cubic.py、certify.py の順に実行する。
すべて標準 Python と SymPy。計算ごとに1 process、数秒で完了した。

最初の位置探しには nroots の数値探索を使った。最終の再現経路では --explore を付けず、記号式だけを生成する。数値探索は根数・符号・不存在の証明には使わない。
探索中、一次 subresultant 共通因子 C を相殺した b 式を C 根へ代入した近似表示が一度出た。
これは C 枝の解ではないため、現行 classify.py は C を例外として飛ばし、cubic.py/certify.py が除算せず完全処理する。
また初版 cubic.py に未整理有理式を多項式剰余へ渡した実装エラーがあったが、該当不要計算を取り除き一次式 resultant の証明へ置き換えた。
符号検査の初版は H 剰余の分子分母を使ったが、極近接した別零点が幅10^−9区間に入り no-root 検査が失敗した。
元の cancel 有理式の分子分母で検査し直して PASS した。失敗を根の正性や不存在の証拠には使っていない。
