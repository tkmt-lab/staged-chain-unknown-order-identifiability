# h=-1付値のQQ cluster分解

q=h+1とする。ここでのHensel分解は有限体からの持上げではなく、Q[[q]]上の計算である。

1. 入力f,gのq内容を除くと、終結式付値には n v(f)+m v(g) が加わる。残精度をその分だけ下げる。必要なら同時Möbius変換k=c+1/zを名目次数m,nで行う。行列式が−1なので終結式付値を保ち、f(0,c),g(0,c)が非零なら両最高係数が単位になる。無限遠にあった根もz=0 clusterとして保持する。
2. 各最高係数の単位級数で割りf,gをモニック化する。これは終結式の単位倍に過ぎない。Q[k]上でf(0,k)=∏a_i(k)^{e_i}と既約分解し、C0=a_i^{e_i}, D0=f(0,k)/C0と置く。C0,D0は互いに素。
3. Henselの補題により、f=C_i D_iを満たす一意なモニック形式級数多項式C_i,D_iがあり、定数項はC0,D0である。実装は係数を順に作る。q^j係数の未処理誤差をE_jとし、C_j=D0^{-1} E_j mod C0、D_j=(E_j−C_jD0)/C0とする。各段の除算剰余零と次数を検査し、全j<NでΣ C_l D_{j−l}=f_jを再検査する。このprefixは上記の一意な形式級数因子のprefixであり、未保存係数を0とは置かない。
4. 別のclusterのC_iは定数項が互いに素なので形式級数環でも互いに素。全clusterの積はモニックfとなる。g(0,k)と互いに素なclusterの終結式は単位なので付値0。それ以外についてgをモニックC_iで割り、r_i=g mod C_iを保存する。Res(C_i,g)=Res(C_i,r_i)である。
5. 保存されたC_i,r_iはq^Nまでの情報のみ。r_iの名目次数はdeg(C_i)−1として保持する（高次の切断係数が零でも、未知のq^N以上の項を削除しない）。`cluster_euclid.py` は `a.precision<=known_q_precision` と局所座標 `point==0` を強制する。したがって各clusterのEuclid付値下界は任意の未知な上位係数にも成立し、真の形式級数因子・真の剰余に適用できる。
6. 元の終結式付値は、内容からの既知分と各cluster付値の和となる。従って各clusterの認証下界の和を取る。途中で残精度不足になった場合も、既に取り出したq冪は下界として有効であるが、必要合計への到達を別に検査する。

`cluster_euclid.py` はdegenerate/qadic_euclid.pyに基づき、名目次数・保存精度の読取り、単位級数によるmonic化、定数項gcdで残終結式が単位と分かる場合の早期停止を加えた。両最高係数が単位の段でf(0,k),g(0,k)が互いに素なら、残終結式の定数項が非零なので付値0。この早期停止は係数膨張を避けるためで、有限体のgcdをQQの零と読む操作ではない。

初期試行は `--target 0 --complete` で全付値を調べた。最終証拠は、有限体で必要精度を選んだ後、各clusterに正の要求下界と保存精度以下の小精度を指定してQQで再計算したもの。個別の `passed:true` だけでは元問題の479/500を意味せず、全clusterの実際の `determinant_valuation_lower_bound` と初期内容の寄与を合計して、元の要求下界と比較する。CLUSTER_CERT_G82/G99.jsonがこの最終集計を固定する。

小対照は f=(k−1)^2(k+2)+q k、g=(k−1)(k+3)+q²。N8で共通clusterのprefix積一致と、直接QQ終結式の付値1に対するcluster付値和1を確認した（CLUSTER_CONTROL_CHECK.json）。
